Features

Everything Midnight Scholar can do for you, all working end-to-end — not just a mockup.

Drag & Drop Upload

Upload PDF, JPG, or PNG files up to 10MB using drag-and-drop or the file picker.

Real PDF Text Extraction

PDFs are parsed on the server with pdf-parse to pull the actual text content, page by page.

OCR for Scanned Images

JPG/PNG uploads run through tesseract.js OCR so handwritten or scanned notes get converted to text too.

AI-Generated Summaries

Extracted text is sent to Claude to generate a genuine, context-aware summary — not a template.

Adjustable Depth

Choose Brief, Balanced, or Detailed and the prompt sent to the AI actually changes length and depth.

Key Takeaways

The AI also returns a distinct list of key points, separate from the narrative summary.

Copy & Download

Copy the summary to your clipboard or save it as a .txt file in one click.

Error Handling & Loading States

Invalid files, oversized uploads, and failed requests are caught and shown clearly, with a live loading indicator during processing.
