About

Midnight Scholar is an AI-powered tool built to cut through the noise of dense documents. Whether it's a 40-page PDF report or a scanned photo of handwritten notes, it extracts the core narrative and vital data points so you can read smarter, not harder.

How it works

Your file is uploaded to a small Node.js/Express backend. PDFs are parsed for text directly; images are run through OCR. The extracted text, along with your chosen summary depth, is sent to Claude, which returns a written summary and a list of key takeaways. Everything you see on the Home page is real, live output — there is no hard-coded demo data.
